DPI vs PPI — and the DPI tag myth

PPI (pixels per inch) belongs to the image: how many of its pixels land on each inch of paper. DPI (dots per inch) belongs to the printer: how many ink dots it lays down. The two are related but not interchangeable, and for working out print size, PPI is the number that matters.

Changing a file's DPI setting adds no detail. The DPI/PPI value stored in a photo file is just a label — a default print-size instruction. A 6000 × 4000 photo tagged at 72 DPI and the same file tagged at 300 DPI contain exactly the same 24 million pixels. The only difference is the size a program suggests first: 6000 ÷ 72 = 83.33 inches at the 72 tag, versus 6000 ÷ 300 = 20 inches at the 300 tag. If an editor "changes DPI" without resampling, no pixel is created or destroyed; if it resamples, it is inventing or discarding pixels, which is a different operation. What decides print quality is always the real pixel count divided by the real printed size — the calculation at the top of this page.

So when a print shop asks for a "300 DPI file", they mean a file whose pixels ÷ intended inches works out to 300 — for example 2400 × 3000 px for an 8×10. Check your size on the dedicated pages below.
